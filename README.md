## 📘 Основы программирования на C

Репозиторий содержит **учебные лабораторные работы по языку C**, выполненные в рамках изучения основ программирования.

## 🧠 Содержание

В репозитории представлены лабораторные работы, охватывающие основные темы языка C, включая:

- базовый синтаксис языка C  
- работа с переменными и типами данных  
- условные операторы (`if`, `switch`)  
- циклы (`for`, `while`, `do-while`)  
- массивы  
- функции  
- работа с вводом и выводом  
- простые алгоритмические задачи

Для компиляции программ используется стандартный компилятор **gcc**.

Пример сборки и запуска отдельной лабораторной работы:
